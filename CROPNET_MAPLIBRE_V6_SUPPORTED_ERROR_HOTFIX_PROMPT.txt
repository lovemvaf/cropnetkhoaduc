NHIỆM VỤ: Trực tiếp sửa lỗi bản đồ vector "Không thể khởi tạo engine bản đồ vector: r.supported is not a function", không dừng ở giải thích hoặc viết kế hoạch. Triển khai Vercel production và kiểm tra hoạt động. Không thay đổi nghiệp vụ khác.

I. LỖI ĐÃ XÁC MINH TỪ CODE
- Tại apps/web/src/features/map/InteractiveDongNaiMap.tsx, trong useEffect initMapLibre, mã đang thực hiện:
  const maplibreMod: any = await import('maplibre-gl');
  const maplibregl = maplibreMod.default || maplibreMod;
  if (!maplibregl.supported()) { ... }
- apps/web/package.json dùng maplibre-gl ^6.14.0.
- MapLibre GL JS v6 không xuất phương thức supported() trên namespace như cách gọi đó; do vậy runtime ném TypeError trước khi tạo map. Bằng chứng: tài liệu MapLibre v6 và hướng dẫn WebGL/GPUInitializationError.
- Các chỗ import và default fallback tương tự còn xuất hiện ở ít nhất ba vị trí trong InteractiveDongNaiMap.tsx (init map, marker/popup, geolocation). Kiểm tra và thống nhất.
- Map style đang dùng https://tiles.openfreemap.org/styles/liberty (cùng bright/positron); giữ hướng keyless hợp lệ, không quay về CARTO có watermark API KEY REQUIRED.
- Root layout đã import maplibre-gl/dist/maplibre-gl.css; tránh import CSS trùng lặp hoặc xóa CSS sai.

II. HOTFIX CẦN LÀM NGAY
1. Bỏ hoàn toàn lời gọi maplibregl.supported() và các kiểm tra dựa vào hàm không tồn tại; KHÔNG thay bằng 'as any', optional chaining hoặc try/catch nuốt lỗi. Dùng namespace import hoặc named import tương thích ESM v6:
   const maplibregl = await import('maplibre-gl');
   const map = new maplibregl.Map({ container: mapContainerRef.current, style: OPEN_FREE_MAP_STYLES.liberty.url, center: DONG_NAI_METROPOLITAN_BOUNDS.center, zoom: DONG_NAI_METROPOLITAN_BOUNDS.defaultZoom, ...giữ các option hợp lệ });
2. Nếu muốn kiểm tra hỗ trợ đồ họa, dùng cơ chế thực sự hỗ trợ bởi phiên bản đang cài: thử tạo map và bắt maplibregl.GPUInitializationError, hoặc kiểm tra WebGL context độc lập; phân biệt lỗi GPU với lỗi worker/network/style. Đừng tự kết luận máy người dùng không hỗ trợ WebGL khi gặp TypeError code.
3. Thống nhất mọi nơi khởi tạo Marker, Popup, Map bằng API v6, kiểm tra `new maplibregl.Marker(...)`, `new maplibregl.Popup(...)`, không sử dụng default export sai. Đặt type có ý nghĩa thay vì any khi có thể.
4. Kiểm tra cấu hình MapLibre GL JS v6 Web Worker trong Next.js 15/webpack/Turbopack production bundle. Nếu báo Worker failed to load, theo hướng dẫn chính thức bố trí đúng file worker vào public/build và setWorkerUrl() MỘT lần trước khi tạo Map; đảm bảo đường dẫn hợp lệ trên Vercel. KHÔNG dùng bừa URL CDN hoặc giả vờ Worker đã chạy. Kiểm tra CSP cho worker-src khi cần. Không tạo lỗi worker bằng cách thêm cấu hình không cần thiết.
5. Bảo đảm useEffect lifecycle đúng trong React StrictMode, không tạo hai map trên một container. Nếu component unmount trong khi dynamic import đang chờ, không tiếp tục tạo map. Gỡ listeners, markers và map.remove() khi unmount; không setState khi component đã unmount. Không làm map trắng do race condition giữa `load` và `style.load`.
6. map.on('load') đánh dấu mapLoaded và dựng polygon/markers; map.on('error') phân biệt network tiles/style/worker/GPU, có cảnh báo thân thiện và log kỹ thuật không lộ secret. Nếu style URL lỗi, dùng phương án dự phòng có quyền sử dụng, không trả hình giả làm bản đồ thực.
7. Rà soát useEffect setStyle: không gọi setStyle cùng style đang sử dụng vô ích mỗi lần mapLoaded chuyển true; sau khi đổi liberty/bright/positron phải khôi phục GeoJSON source/layer ranh giới, marker và trạng thái chọn đúng thứ tự. Tránh listener `style.load` tích lũy, tránh popup biến mất.
8. Xác minh mapContainer có chiều cao thật trên mobile/desktop; canvas không bị overlay lỗi che, không có horizontal overflow. Giữ và hiển thị attribution bắt buộc của OpenStreetMap/OpenFreeMap. UI thống nhất thiết kế CropNet; không gradient, watermark sai hoặc nhãn giả lập.
